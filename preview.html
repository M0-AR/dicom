Quickstart

Sixty seconds from clone to PACS.

You need Python 3.10+ and nothing else. The defaults send to a local Orthanc. Point the flags at your own server when you are ready.

terminal
# 1. get the code
git clone https://github.com/M0-AR/dicom.git
cd dicom

# 2. install (isolated environment)
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. create a safe synthetic study
python generate_dicom.py

# 4. send it to your PACS
python dicom_server_request.py --host 127.0.0.1 --port 4242 --echo

DICOM FORGESynthetic Imaging Lab

An educational and engineering toolkit for synthetic DICOM generation and C-STORE integration testing. Built on the open DICOM standard.

The interactive lab uses de-identified CT data from the PCIR dataset (CC0 1.0).
